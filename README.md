# Charlotte Political Power Mapping Case Study

## Project Overview
This project is a localized case study of the **Political Power Mapping Engine**. It applies the Python OSINT pipeline to map the political ecosystem of Charlotte, North Carolina. The goal is to identify the corporate donors, real estate developers, and political allies that keep the local political machine in power.

## The Objective
Local AfroSocialist and progressive organizers needed a strategic map of the terrain. The goal was to identify the "Winning Coalition" of targeted city council and state representatives. By understanding their network, organizers could identify which allies were vulnerable to public pressure, and which donors to target in public campaigns.

## Methodology
1.  **Target Selection:** Selected 5 key incumbent politicians in the Charlotte area.
2.  **Data Aggregation:** Scraped NC State Board of Elections finance data for these 5 politicians over the last 2 election cycles.
3.  **Network Construction:** Mapped the financial connections between the politicians and local real estate, finance, and healthcare PACs.
4.  **Bipartisan Analysis:** Identified overlapping donors between seemingly opposed politicians (e.g., moderate Democrats and conservative Republicans both funded by the same real estate lobby).
